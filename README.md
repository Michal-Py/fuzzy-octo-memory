# Interactive-Dashboard-Practice
Interactive Dashboard Practice 

### About the project
Two sample sales dashboards built in Power BI to practise data analysis and report design. Both are interactive and use DAX measures. The data is fictional and was created by me for learning purposes only.

### Dashboards
**1. Basic dashboard**
A simple, minimal report with core metrics and a few standard charts. Its purpose is to show the basics of building a report.

**2. Advanced dashboard**
The same kind of analysis with a much more developed visual design: a custom colour theme, a consistent layout, formatted cards and charts, and a clear visual hierarchy.

### Features
- Interactive filters (slicers) and cross-filtering between visuals
- Calculations written in DAX (measures and calculated columns)
- Two different design approaches to the same data

### Tools
Power BI Desktop, DAX, Excel


### O projekcie
Dwa przykładowe dashboardy sprzedażowe wykonane w Power BI, które stworzyłem, żeby ćwiczyć analizę danych i projektowanie raportów. Oba są interaktywne i wykorzystują miary w języku DAX. Dane są fikcyjne i zostały przygotowane przeze mnie wyłącznie w celach edukacyjnych.

### Dashboardy
**1. Dashboard podstawowy**
Prosty, minimalistyczny raport z podstawowymi wskaźnikami i kilkoma standardowymi wykresami. Pokazuje podstawy budowy raportu.

**2. Dashboard zaawansowany**
Ten sam rodzaj analizy z mocno dopracowaną szatą graficzną: własny motyw kolorystyczny, spójny układ, sformatowane karty i wykresy oraz czytelna hierarchia wizualna.

### Funkcje
- Interaktywne filtry (fragmentatory) i wzajemne filtrowanie wizualizacji
- Obliczenia w języku DAX (miary i kolumny obliczeniowe)
- Dwa różne podejścia do projektu graficznego na tych samych danych

### Narzędzia
Power BI Desktop, DAX, Excel
